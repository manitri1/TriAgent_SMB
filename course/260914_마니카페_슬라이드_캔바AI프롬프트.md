## 메인 프롬프트 (그대로 복사해서 붙여넣기)

```
1인 카페 사장님을 위한 AI 운영 콘솔 "마니카페"의 도입 전/후를 비교하는
정확히 2장짜리 비즈니스 프레젠테이션을 만들어줘. 청중은 스타트업 데모데이
심사위원이고, 톤은 과장 없이 실측 데이터로 신뢰를 주는 스타일이야. 슬라이드를
추가하지 말고 정확히 2장만 만들어줘.

디자인 스타일: 깔끔한 SaaS 대시보드 느낌, 미니멀, 데이터 중심. 메인 컬러는
바이올렛 계열(#5B3DF0)에 밝은 라벤더 배경(#F3F0FB), 텍스트는 짙은 남보라
(#1C1730). 한글 산세리프 폰트(Noto Sans KR 계열), 숫자는 굵고 크게 강조.
카드형 레이아웃과 표를 적극 활용하고, 이모지나 클립아트 대신 컬러 점/아이콘
정도만 절제해서 사용해줘.

[슬라이드 1 — 제목: "같은 하루, 다른 부담 — 사장님이 직접 vs 7개 에이전트가 함께"]
상단에 작은 라벨 "BEFORE & AFTER"를 넣고, 아래에 두 칼럼을 나란히 배치해줘.

왼쪽 칼럼 제목: "기존 방식 — 사장님 1인 체제" (회색 톤)
- 재고를 손으로 세어 수첩에 적고, 어제 숫자와 안 맞으면 재확인
- 전화 예약·문의를 접객 중 놓쳐 응답이 30분씩 지연
- 주문·결제·조리를 동시에 하다 결제 금액 오입력
- 홍보 문구 쓸 시간이 없어 이번 주도 SNS를 건너뜀
- 마감 정산을 손으로 대조, 안 맞으면 처음부터 재계산
- 안전장치 없이 모든 결정을 혼자, 즉석에서 내림

오른쪽 칼럼 제목: "AI 에이전트 방식 — coordinator + 6개 전문 에이전트" (바이올렛 강조,
체크마크 스타일)
- inventory-agent가 새벽에 재고 스냅샷을 정리해 카드로 제시
- reservation-agent가 즉시 등록, coordinator는 신규 건만 알림
- order-payment-agent가 결제를 맡아 사장님은 조리에 집중
- marketing-crm-agent가 데이터 기반 홍보 초안 4종을 스스로 제안
- sales-analytics-agent가 마감 리포트를 자동 정리
- 돈이 오가거나 손님에게 나가는 3곳만 사장님이 최종 승인(HITL)

하단에 4개의 숫자 카드를 가로로 배치:
1) "12 → 3" / 사장님이 직접 처리해야 하는 접점(12건 중 3건, 75% 감소)
2) "7" / 동시에 움직이는 profile — coordinator + 전문 에이전트 6개
3) "3" / HITL 승인 게이트 — 발주 15만원 초과 / 결제·환불 / 마케팅 집행
4) "6/6" / 사장님 페인포인트 6개 유형, 전부 에이전트가 1차 대응

[슬라이드 2 — 제목: "실측으로 뒷받침한 숫자, 그리고 아직 못 한 것"]
상단에 작은 라벨 "정량적 증거 & 정직한 한계"를 넣어줘.

6개의 숫자 카드를 3x2 그리드로 배치:
1) "3분 39초" / 주문 접수 → 결제 완료 e2e 실측(자동·무인 처리)
2) "25초~4분" / coordinator 위임 응답 시간 실측 범위 — 지연돼도 재조회로 처리
   완료 확인
3) "123건" / 자동화 테스트 전량 통과(webapp 98 + mock-pos 25) — 매 배포 전
   필수 확인
4) "12/12" / "사장님의 하루" 전체 시나리오, 실제 웹앱에서 재현 가능
5) "4종" / 마케팅·CRM 제안(VIP 감사·이탈 재유치·판매저조 홍보·인기메뉴
   프로모션) — 클릭 1회로 초안 요청
6) "0 → 자동" / "오늘 매출 0" 표시 오류를 자가치유 백그라운드 작업으로
   매시간 자동 보정(신규 도입)

하단에 두 개의 박스를 나란히:
왼쪽 박스(노란/앰버 톤, 제목 "정직하게 밝히는 한계"):
- 전화·음성 응대는 여전히 사람이 수행(에이전트는 텍스트 요청만 처리)
- 카카오톡 미연동 — 표기상 접점은 Discord·웹 콘솔로 대체 시연
- 홍보 문구는 승인 후에도 사장님이 직접 게시(자동 게시 연동 전)
- 가격정책·구독 수익 구조는 아직 설계 전

오른쪽 박스(짙은 남보라 배경, 흰 글씨, 제목 "그래도 남는 것 — 차별점"):
매장에 쌓이는 운영 데이터, 사장님이 이미 익힌 승인 흐름(전환 비용),
"AI가 마음대로 결제·발주·홍보를 하지 않는다"는 확인 가능한 신뢰 장치.

숫자는 표에 적힌 그대로 정확히 써주고, 새로운 통계나 사례를 지어내지 마.
```
