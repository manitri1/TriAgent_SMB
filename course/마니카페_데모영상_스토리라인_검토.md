# 데모 영상 스토리라인 검토 — "커피 향을 되찾은 사장님의 하루"

**검토 대상**: 사용자가 제안한 Before/After 7씬 영상 스토리라인 (AX상회 'Done-for-you' 서비스 홍보)
**검토 기준**: TriAgent_SMB 실제 구현·검증 상태 ([README.md](../README.md), [webapp/README.md](../webapp/README.md), [docs/07-roadmap.md](../docs/07-roadmap.md), [docs/21-live-demo-plan.md](../docs/21-live-demo-plan.md))
**작성일**: 2026-09-11

---

## 1. 강점

- Before(반복 응대·노쇼·야근)와 After(자동 응대·리마인드·조기 퇴근)의 대비가 명확하고, 실제 페인포인트([course/마니카페_사장님의_하루.md](마니카페_사장님의_하루.md)의 12개 타임라인)와 결이 일치한다.
- Scene 5에서 "민감한 건만 사장님 승인 요청 → [승인] 시 완결"을 넣은 것은 HITL(사람 승인 게이트) 설계 철학을 정확히 담고 있다. 실제로 이 프로젝트의 핵심 차별점(AI가 돈이 걸린 결정을 스스로 하지 않음)과 일치한다.
- Scene 7의 "숫자로 증명" 엔딩 구조는 인포그래픽 레퍼런스의 톤을 잘 계승했다.

## 3. 대신 넣을 수 있는 "실측 완료" 소재

과장 없이 신뢰를 주려면 아래처럼 **실제로 검증된 사실**을 엔딩/중간 자막에 섞어 쓰는 것을 권장한다.

- 7개 에이전트 프로필 전체 + coordinator 오케스트레이션 실제 챗 검증 완료
- HITL 승인 게이트 3종(프로모션·대량발주·환불) 모두 승인 없이는 실행되지 않음을 실측 확인
- webapp 4화면(고객문의·주문접수·재고·대시보드) 실제 컨테이너에서 end-to-end 검증 완료 (2026-09-04)
- 실제 주문("카푸치노 1잔")이 결제 완료 → 오늘 매출에 반영되는 것까지 확인 (3분 39초 소요)

## 4. 기존 자산과의 정합성 — 새로 만들지 말고 각색을 권장

이미 이 프로젝트에는 같은 세계관(마니카페, HITL 3게이트, 7-에이전트)을 가진 두 자산이 있다.

- **[마니카페_사장님의_하루.md](마니카페_사장님의_하루.md)** — 12개 타임라인 Before/After 비교 (이미 사실관계 검증됨: 승인 임계값 15만원, 게이트 3곳)
- **[docs/21-live-demo-plan.md](../docs/21-live-demo-plan.md)** — 같은 타임라인을 실제 VPS에서 라이브로 시연하기 위한 실행 계획 (채널 매핑까지 이미 확정: webapp/CLI/Discord)

**권장**: 이번 7씬 감성 영상을 완전히 새로 쓰기보다, 위 12-타임라인 중 감정선이 강한 5~6개(재고 결품·컴플레인·마감정산·승인확인 등)를 뽑아 영상용으로 압축하는 방식을 추천한다. 그러면 채널명·수치·승인 흐름을 매번 새로 검증할 필요 없이 이미 맞춰둔 사실관계를 그대로 물려받는다.

## 5. 두 가지 제작 방향 제안

| 방향 | 설명 | 언제 적합한가 |
|---|---|---|
| **A. 비전 필름** | 실 POS 연동·음성·리뷰응답 등 로드맵 항목까지 포함해 "AX상회가 그리는 목표"를 그린다. 단, 자막/내레이션에 "목표", "예정"을 명시해 과장 논란을 방지 | 투자 유치·비전 공유용 |
| **B. 실측 데모 필름** | 지금 클릭 한 번으로 재현 가능한 것만 담는다 (webapp 4화면 + Discord 브리핑 + HITL 게이트 실사용 장면). [docs/21-live-demo-plan.md](../docs/21-live-demo-plan.md) P2 채널 매핑을 그대로 따름 | 심사·데모데이 등 "지금 되는 것"을 증명해야 하는 자리 |

## 6. 결론

원본 스토리라인은 **감정선과 구조는 그대로 쓸 만하지만, 카카오톡·음성·리뷰응답·실POS연동·버튼승인 등 5~6곳이 아직 구현되지 않은 기능을 이미 있는 것처럼 서술**하고 있다. 데모데이/심사 자리라면 위 표의 수정안을 반영해 "지금 실제로 되는 것" 위주로 다시 짜는 것을(방향 B) 권장하고, 홍보용 비전 영상이라면 "목표"임을 명시하는 것(방향 A)을 권장한다.
